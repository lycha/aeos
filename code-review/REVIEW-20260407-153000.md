## Minor Issues

### m1. `.idea/misc.xml` deleted — consider adding `.idea/` to `.gitignore`

**File:** `.idea/misc.xml` (deleted) / `.gitignore`

**Problem:**
The commit deletes `.idea/misc.xml` (an IntelliJ project file), which is correct — IDE files shouldn't be tracked. However, `.idea/` is not in the project `.gitignore`, so future IntelliJ-generated files could be accidentally committed again. The global gitignore was configured for `.aeos/` but not for `.idea/`.

**Recommendation:**
Add `.idea/` to `.gitignore`:
```
# IDE
.idea/
```

### m2. ESLint `ignores` pattern missing — linting may pick up config files

**File:** `eslint.config.js`

**Problem:**
The ESLint flat config does not declare an `ignores` array. ESLint 9+ flat config has no `.eslintignore` equivalent — you must use `ignores` in the config. Without it, ESLint could attempt to lint `vitest.config.ts`, `eslint.config.js` itself, or files in `dist/` and `coverage/` if they exist. The current lint script uses `'src/**/*.ts'` glob which mitigates this in practice, but if the script is ever changed to `eslint .`, it will break.

**Recommendation:**
Add a global ignores entry as the first config object:
```js
export default tseslint.config(
  {
    ignores: ['dist/', 'coverage/', 'node_modules/'],
  },
  ...tseslint.configs.recommended,
  eslintConfigPrettier,
  {
    rules: {
      'no-console': 'warn',
      '@typescript-eslint/no-explicit-any': 'error',
    },
  },
);
```

### m4. `package.json` `"directories": { "doc": "docs" }` leftover from `npm init`

**File:** `package.json`

**Problem:**
`npm init -y` auto-detects the `docs/` directory and adds `"directories": { "doc": "docs" }`. This field is a vestigial npm convention that provides no value and adds noise.

**Recommendation:**
Remove the `"directories"` block from `package.json`:
```diff
-  "directories": {
-    "doc": "docs"
-  },
```
