# Welcome to the aeos!

**Aeos** or **Æos** may refer to:


-&gt; **Aeos**, the mythological horse that drew the Sun Chariot with 3 other horses across the sky with the Greek god Helios,


-&gt; **Agentic Engineering Operating System**, an interface where the human operator controls flow, reviews outputs, and maintains final authority over every significant implementation decision



**AEOS** is a CLI that drives tickets through LLM-agent pipelines — each stage has a worker agent, a reviewer agent, and a human approval gate. But also it's an approach for implementing the 12 Principles of AI Driven Development.
